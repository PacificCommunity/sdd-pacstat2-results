# sdd-pacstat2-results
Code for monitoring the project development objective indicator and some of the intermediat indicators of the Innovation and Capacity Building for Pacific Statistics, Phase 2 project (PacStat2), funded by the World Bank and implemented by SPC, Kiribati, Tonga and Tuvalu.

For example, by monitoring the completeness by country of official statistics such as estimates of population, SDG indicators, etc
